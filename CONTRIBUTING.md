# Contributing

Thanks for helping improve Portfolio Agent Widget. Bug reports, documentation improvements, accessibility fixes, and focused pull requests are welcome.

## Before opening a pull request

1. Open an issue for significant changes so the approach can be discussed first.
2. Fork the repository and create a branch for your change.
3. Run `npm ci`, `npm test`, and `npm pack --dry-run` with Node.js 20.6 or newer.
4. Update the README and tests when behavior or the public API changes.
5. Keep API keys, personal contact details, and real candidate profiles out of commits and test fixtures.

Please make pull requests small enough to review and describe what changed, why, and how it was tested. By contributing, you agree that your contribution is licensed under the repository's MIT License.
