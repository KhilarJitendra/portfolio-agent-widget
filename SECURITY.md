# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting feature from this repository's **Security** tab. If that option is unavailable, contact the maintainer privately through their GitHub profile.

Include a description, reproduction steps, affected versions, and potential impact. Do not include live API keys or private profile data in a report.

## Supported versions

Security fixes are provided for the latest released version when feasible. The project is currently pre-1.0, so APIs may change between minor releases.
